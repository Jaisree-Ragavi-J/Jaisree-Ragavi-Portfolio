# Jaisree Ragavi J — Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. It showcases professional experience, skills, projects, education, achievements, leadership, and contact links.

## Development

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

Vite prints the local URL after the server starts.

## Validation

```sh
npm run build
npm test
npm run lint
```
